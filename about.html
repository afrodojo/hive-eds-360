Core Research Investigations

Sovereign AI & Air-Gapped Enclaves

Architecting fully isolated 5-node compute clusters (vm-node1 through vm-node5) with non-routable host networking, zero external cloud dependencies, and hardware-attested cryptographic boundaries.

eBPF Kernel Egress Quarantine

Enforcing Layer-0 security policies using extended Berkeley Packet Filters directly in Linux Ring-0 to eliminate side-channel data exfiltration and block unauthorized socket creation at the system call boundary.

SMT/SAT Constrained Decoding

Replacing probabilistic output filtering with formal Satisfiability Modulo Theories (Z3 solver). Invariants prune violating logits during auto-regressive generation to guarantee mathematically verified inference.

Differential Privacy in Vector Retrieval

Hardening offline vector databases against embedding inversion and membership inference attacks using mathematically bounded Gaussian noise injection and Merkle-DAG integrity validation.
